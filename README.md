# AsterVale AI Visibility Analysis — Kasparro Data Analyst Assignment

End-to-end pipeline that audits **AsterVale's visibility in AI-generated responses** (ChatGPT, Gemini, Perplexity, Claude) versus five competitor brands across Month 1 (June 2026) and Month 2 (July 2026).

---

## Key Results

| Period | ASV Score | Non-Branded Discovery | Branded Performance |
|---|---|---|---|
| Month 1 Baseline | 31.45 / 100 | 10.85 / 100 | 62.34 / 100 |
| Month 2 (Matched) | 43.91 / 100 | 23.09 / 100 | 75.14 / 100 |
| Movement | **+12.32 pp (+39%)** | +12.00 pp (+108%) | +12.80 pp (+21%) |

> Temporal movement does not imply direct causation. Results reflect correlation with content fixes F01–F05, AI platform updates, and sampling variability.

## Setup & Execution

### Requirements
- Python 3.10+

### Install dependencies
```bash
pip install -r requirements.txt
```

### Run the pipeline
Execute from the `AsterVale_Assignment_Organized/` root directory:

```bash
python 02_Source_Code/run_visibility_analysis.py
```

The pipeline will regenerate all 11 CSV outputs in `05_Analysis_Outputs/` and overwrite `06_Final_Deliverables/astervale_ai_visibility_executive_report.pdf`.

> **Note:** All reported numbers are computed dynamically from the raw input data. No values are hardcoded.

---

## Analysis Workflow

1. **Ingest & Deduplicate** — Loads JSONL run records, deduplicates by latest `ingested_at` per `run_id`.
2. **Eligibility & QA** — Enforces platform/replicate scope, 5-brand completeness, boolean hierarchy (`top_choice → recommended → shortlisted → mentioned`), rank validity, and URL canonicalization.
3. **Month 1 Baseline** — Computes all 11 metrics on the 375 eligible June 2026 runs.
4. **Matched M1 vs M2 Comparison** — Filters to the 366-cell matched cohort (same `prompt_id × platform × replicate` in both months).
5. **Driver Breakdown** — Decomposes movement by prompt family and AI platform.
6. **Fix Assessment** — Evaluates content fixes F01–F07 against observed metric deltas; classifies each as `consistent_with_improvement`, `mixed`, `no_observable_support`, or `not_evaluable_month_2`.
7. **SQL Analytics** — Queries GSC and GA4 data from the SQLite database for corroborating search/traffic context.
8. **Executive Memo** — Generates a 3-page PDF presentation with all dynamic metrics bound from the CSV outputs.
